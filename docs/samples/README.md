# Samples (not committed)

Drop redacted HDFC alert emails here as `.eml` (one per alert type: UPI debit, debit card,
NEFT/IMPS, ACH/SI, ATM, credit) plus one statement `.xls`/`.csv` and one `.pdf`.
Replace real account numbers, names and amounts if you like; keep the sentence structure intact,
that is what the parsers are built against. These files are git-ignored.
